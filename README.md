# 🕌 Qaza Namaz Pro — Smart Qaza Tracker

A modern, offline-first **Qaza Namaz (Missed Prayers) Tracker** built with HTML, CSS, and JavaScript.

The app helps users calculate, track, and complete missed prayers in an organized way. It includes profile management, prayer tracking, progress reports, certificates, theme switching, and Urdu/English language support.

---

## ✨ Features

### 📊 Dashboard
- Personal profile information
- Total estimated Qaza prayers
- Completed prayers
- Remaining prayers
- Progress tracking
- Daily/overall statistics
- Prayer completion streaks and badges

### 🕌 Qaza Prayer Calculation
- Calculate missed prayers based on years
- Monthly prayer estimation
- Different prayer frequency options
- Supports:
  - Fajr
  - Dhuhr
  - Asr
  - Maghrib
  - Isha
  - Witr

### ✅ Prayer Entry
- Record completed Qaza prayers
- Track individual prayer progress
- Update remaining Qaza prayers
- Easy daily progress tracking

### 📈 Reports
- Detailed Qaza progress
- Prayer-wise statistics
- Completion information
- Visual progress charts
- Report generation

### 🏆 Certificates
- Silver certificates for individual prayers
- Golden certificate for completing all Qaza prayers
- Certificate information based on the user's profile
- Printable PDF certificates

### 🌐 Language Support
The application supports two languages:

- 🇵🇰 **اردو (Urdu)**
- 🇬🇧 **English**

Switching the language changes the application's interface accordingly.

### 🌙 Theme Support
- ☀️ Day Mode
- 🌙 Night Mode
- Responsive text colors
- Optimized readability in both themes

### 📄 PDF / Print
- Printable progress reports
- Individual prayer certificates
- Golden completion certificate
- Print-friendly layouts
- Designed to avoid unnecessary blank pages

### 💾 Offline Support
The application is designed to work locally in the browser without requiring a server or database.
